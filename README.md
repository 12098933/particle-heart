# 粒子爱心、单手手势与回忆相册

页面文件：`index.html`

手势控制：`gesture.js` + `gesture-worker.js` + MediaPipe Hand Landmarker

回忆相册：`gallery.js` + 6 张内置本地照片

## 视频中的核心机制

爱心不是一张旋转图片，而是由大量独立粒子组成的三维点云。粒子的分散和重组由四层共同产生：

1. **心形采样**

   用二维心形参数方程生成 `(x, y)`，再给每个点加入前后方向的 `z` 随机厚度。这样正面是爱心，侧面旋转时仍然有体积。

2. **单手掌心开合触发**

   手指伸展数量实时映射为扩散目标：握合手掌时重组成完整爱心，张开手掌时散成星尘云。

3. **快速连续插值**

   每颗粒子都有爱心位置和星尘云位置。手指动作触发后立即改变形态目标：

   ```text
   target = 0.7 * fingerSpread + 0.3 * extendedRatio
   spread += (target - spread) * (1 - exp(-dt / 82))
   position = mix(heart, cloud, spread) + swirl
   ```

   约 80ms 的响应曲线让动作开始后立即看到粒子反馈，同时保留柔和过渡。

4. **三维旋转与叠加发光**

   整个粒子组绕 Y 轴缓慢旋转，Camera 使用透视投影。粒子的屏幕尺寸随深度变化，红、橙、金三种颜色使用 Additive Blending 叠加，形成视频中的暖色光晕。

## 真人手势交互

参考视频右侧有一个实时手部画面，动作包括指向、张开手掌、捏合和横向移动。这里使用浏览器摄像头和 MediaPipe 的 21 个手部关键点复现同样的交互：

- **指向并移动**：按手掌中心相对初始位置的位移控制爱心旋转和俯仰。
- **张开手掌**：粒子实时散开成星尘云。
- **握合手掌**：粒子实时缩小并重新聚合成爱心。
- **单指捏合一次**：唯一允许打开或收起回忆相册的手势。
- **张开手掌横划**：相册打开后切换上一张/下一张照片。
- **食指引路**：在画面上绘制金色光迹，同时控制爱心的空间方向。
- **双指捏合**：相册打开时缩放当前照片。
- **捏合后松开**：发射一圈星尘粒子，并给爱心一次能量脉冲。

所有操作都使用单手完成。手掌位置驱动粒子的 X/Y/Z 位移与三轴旋转，掌心开合控制扩散和重组；捏合控制相册。摄像头默认关闭，点击底部相机图标后才会请求权限。视频画面只在本机处理，不会上传。

## 实时粒子响应

每帧检测指尖离掌心距离与伸展手指数，按 `70%` 指尖张开程度和 `30%` 手指伸展比例计算目标扩散值。粒子响应时间常数为 82ms，实测约 100ms 内即可看到明显扩散和重组反馈；手离开画面后会平滑回到完整爱心。

## 无法识别手势时

页面现在会自动执行三层容错：

1. 优先使用 GPU 推理，无法创建或长时间没有检测结果时自动切换到 CPU。
2. 全画幅没有发现手时，交替对中央 76% 区域放大检测，手稍远也能识别。
3. 推理异常时自动重建识别器，不再直接关闭摄像头。

状态区会实时显示 `SHOW HAND`、`NO HAND`、`OPEN PALM`、`PINCH`、`POINT`，以及当前使用的推理后端。若一直显示 `NO HAND`：

- 使用 Chrome 或 Edge 打开 `http://127.0.0.1:4173/`，不要直接打开 HTML 文件。
- 点击底部相机按钮，并允许浏览器摄像头权限。
- 让整只手进入右侧取景框，手腕到手肘不必入镜。
- 手与摄像头保持约 40-80 厘米，避免强逆光；普通室内照明即可。
- 捏合动作要让拇指和食指真正靠近，张开手掌要让四根手指都伸展开。

## 回忆相册

相册内置 6 张本地照片。相册入口受手势锁保护，只有**单指捏合一次**才能打开；再次单指捏合可以关闭。点击控制栏中的图片图标只会显示解锁提示，不会直接查看照片。打开后支持：

- 鼠标拖拽、左右按钮或键盘方向键切换照片。
- 张开手掌左右挥动，通过手势切换照片。
- 双指捏合放大当前照片，松开恢复。
- 点击“添加照片”选择本机图片，支持一次选择多张。
- 把图片拖入相册也可以直接添加。
- 自定义照片存储在浏览器 IndexedDB 中，刷新后仍然保留。
- 所有照片都可以通过“移除”按钮删除，包括内置六张。
- 删除全部照片后会显示空相册状态，可继续添加新照片。
- “恢复默认”会重新加入被删除的内置照片。

单张原始图片上限 24MB，自定义照片最多 24 张。上传后会在浏览器本地压缩，不会发送到服务器。照片列表和来源记录在 `images/CREDITS.md`。

推荐使用 JPG、PNG、WebP 或 AVIF。HEIC 是否能读取取决于浏览器自身的图片解码能力。

## 新增交互

- **实时手部光迹**：索引指尖在完整画面中留下 620ms 的金色拖尾，反馈频率独立于粒子动画。
- **捏合星尘**：捏合释放会生成随机方向的粒子火花。
- **照片记忆切换**：照片切换、粒子脉冲和手部反馈同步触发。
- **相册光门**：相册开启时会经过光晕扩散、3D 翻转和六片百叶依次收起的入场动画。
- **自适应画质**：桌面优先 1080p/30fps，手机优先 720p/30fps，并按设备能力逐级降级，优先保证手势实时响应。
- **最高美颜**：保留摄像头原始清晰层，再叠加肤色柔化、暖光、亮度和低对比度柔化。

## 可调参数

在 `index.html` 的脚本中可以调整：

- `PARTICLE_COUNT`：粒子数量。
- `heartScale`：整个爱心的尺寸。
- `depth` 计算中的 `1.02`：爱心厚度。
- `rotationAngle += delta * 0.00021`：自动旋转速度。
- `cloudPositions`：星尘云的分布范围。
- `updateParticleSpread` 中的 `82`：粒子响应时间常数，数值越小反馈越快。
- `fingerSpread` 与 `extendedRatio`：手掌开合程度到扩散值的映射。
- `outputWidth = useCrop ? 560 : 512`：手势检测分辨率，兼顾速度与精度。
- `now - lastDetectionTime < 50`：手势检测最短间隔，给渲染线程保留稳定帧时间。

## 性能优化

- MediaPipe 推理运行在独立 Web Worker 中，避免阻塞 Three.js 渲染主线程。
- Worker 模式使用 CPU 推理以隔离主线程；Worker 不可用时才回退到主线程的 GPU/CPU 引擎。
- 完整画面使用 512px 检测，小目标回退到 560px 中央裁剪。
- 位置、倾斜、缩放与滚转使用与帧率无关的指数阻尼，避免掉帧时出现跳动。
- 手部光迹用独立 2D Canvas 以 60fps 渲染，不受模型推理帧率限制。
- WebGL 像素比上限收紧到 1.5，手部光迹层使用原生分辨率，减少高 DPI 填充压力。
- 相册缩略图使用独立 180×225 小图，避免加载多张完整照片。
- 上传照片在写入 IndexedDB 前会限制到 1600×2000 并重新压缩。

## 运行方式

访问 `http://127.0.0.1:4173/`。手势识别需要摄像头和 localhost 安全上下文，因此不建议直接双击打开 HTML。

页面启动后会先显示密码锁，访问密码为 `061209`。支持数字键盘、实体键盘数字键、退格、清除和回车提交；解锁后才会显示页面并启用摄像头。

首次通过公网分享地址启动手势时，浏览器需要下载约 8 MB 的压缩后模型资源。状态会依次显示 `MODEL LINK`、`AI RUNTIME`、`HAND MODEL`；完成后自动缓存，后续启动会明显加快。微信、抖音等内置浏览器可能拦截摄像头，请使用右上角菜单选择“在浏览器中打开”，再使用 Safari、Chrome 或 Edge。

不要使用 `file:///.../index.html` 打开。浏览器会拦截 ES Module，导致 `gesture.js` 不执行，表现就是手势按钮存在但没有反应。页面现在会识别这种打开方式，并显示跳转到正确地址的提示。

页面同时提供两处手势入口：

- 底部右侧的“手势交互”相机按钮。
- 控制栏内的相机图标。

相册不能通过鼠标或键盘直接打开，必须先完成单指捏合手势。关闭相册后可以再次用同样手势打开。

## 全屏与独立窗口

- 点击控制栏中的全屏按钮可进入浏览器全屏，按 `F` 或双击画面也可以切换。
- 页面包含 `manifest.webmanifest`、192px 和 512px 应用图标，支持在 Chrome/Edge 中安装为独立应用。
- 手机可添加到主屏幕，以 `fullscreen` 或 `standalone` 模式启动，不显示网页地址栏。
